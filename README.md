UnlimitedAI gives developers a single OpenAI- and Anthropic-compatible API for Claude, GPT, DeepSeek, GLM, Kimi, and Qwen models. Use one API key across Claude Code, Codex, Cursor, Cline, OpenCode, Aider, VS Code, and other tools that support a custom AI endpoint.

## Why developers use UnlimitedAI

- Flat-price access for 28 days instead of per-token billing
- No token meter on supported plans; concurrency is set by the plan
- Up to 1M-token context on supported models
- One endpoint and one key for multiple model families
- Useful for coding agents, long documents, research, and large repositories

## Models

The lineup includes Claude Haiku, Sonnet, and Opus; GPT-6; DeepSeek V4; GLM 5; Kimi K3; and Qwen3.8-Max. Check the live model list and plan details on the official site.
